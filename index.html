      lan drop local.

      For networks with no internet: a router on its own, a phone hotspot without data, or two computers joined by an Ethernet cable. The computer that shares the folder runs this small program. Everyone else opens the address it shows, in any browser. Files go straight across the local network at full speed.

      Download
        Windows: if SmartScreen warns, click More info → Run anyway, and allow the firewall prompt. Mac: unzip, then right-click → Open the first time. The program isn't code-signed yet. All versions and notes: GitHub releases.
        Host · one-time setting

        turn on direct connections.

        For privacy, Chrome and Edge hide this computer's local network address behind a random name. Many networks can't look those names up, so people on your own network end up going through the relay, out to the internet and back. Letting this browser show its local address lets them connect straight through your router. Only this computer, the host, needs it.

        1. Copy this address and open it in a new tab of this browser:
          chrome://flags/#enable-webrtc-hide-local-ips-with-mdns
          In Edge: edge://flags/#enable-webrtc-hide-local-ips-with-mdns
        2. Set Anonymize local IPs exposed by WebRTC to Disabled, then click Relaunch.
        3. Come back here and click Resume sharing. Your code stays the same, and people reconnect on their own. Their route should then read "direct · same network".
        With this off, websites you use in this browser can see this computer's local network address (for example 192.168.1.20). It only means something inside your network. If your browser no longer lists that setting, or your computer is managed by IT, the policy WebRtcLocalIpsAllowedUrls set to https://mikkaiser.github.io does the same for this site only. Some networks, often staff and guest Wi-Fi, block devices from reaching each other at all. There the relay is the only route, whatever this setting says.
